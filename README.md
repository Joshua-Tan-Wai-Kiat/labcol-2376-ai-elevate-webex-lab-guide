# LABCOL-2376 public lab guide

This repository publishes a public, web-friendly edition of the Cisco Live Melbourne 2026 **Next-Gen Calling: AI-Elevate with Webex** lab.

The source Word document, embedded screenshots, credentials, session endpoints, and example passwords are deliberately excluded. Use the private details assigned to your own lab pod.

## Preview

```powershell
$env:PYTHONPATH = "..\\.local-deps"
python -m mkdocs serve
```

## Publish with GitHub Pages

The included workflow publishes every push to `main`. In the GitHub repository, select **Settings > Pages > Build and deployment > GitHub Actions**.
